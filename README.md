# Эмулятор оболочки ОС

Лабораторная работа по дисциплине «Конфигурационное управление».
Вариант №14.

## Описание

Эмулятор командной строки UNIX-подобной ОС на Python.

## Этапы

- **Этап 1** — REPL (диалог с пользователем, заглушки `ls`/`cd`, `exit`)
- **Этап 2** — конфигурация (параметры CLI, VFS, стартовые скрипты)

## Требования

- Python 3.10+

## Запуск

Интерактивный режим:
python src/shell.py
С параметрами:
## Параметры

| Параметр | Описание |
|---|---|
| `--vfs` | Путь к JSON-файлу виртуальной файловой системы |
| `--script` | Путь к стартовому скрипту с командами |
